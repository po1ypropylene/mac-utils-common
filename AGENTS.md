# Shared guidance for macOS utilities

For changes to building, installing, or managing a macOS background command-line
utility, read [the reusable service instructions](docs/macos-background-services.md).
These instructions are self-contained; no example repository is required.

Read the target repository's own instructions and adapt the generic examples to
its name, service identifier, runtime options, and permission requirements.
Keep its README commands aligned with its scripts. Modify only repositories and
files within the user-authorized scope; treat any reference repositories as
read-only unless the user explicitly authorizes changes.
